# v0.4.1 — Release documentation gate

## Changes

- Added a release documentation check that requires versioned release notes and a checked-in review record with evidence for each documentation surface.
- Added release documentation validation to repository CI for new package versions, including version alignment and local Markdown link checks.
- Reconciled the README, command specifications, recovery guidance, and release workflow with the shipped 0.4.0 commands.

## Safety and compatibility

This release changes release preparation and CI checks. It does not change `dbh` command behavior, configuration, or backup data. The repository validation workflow skips the documentation gate for ordinary development changes at the already released package version and enforces it for a new release version.

## Install and verify

Install or update the CLI, then confirm the installed version:

```bash
npm install --global @dodefey/db-helper@0.4.1
dbh --version
```

The version command should print `dbh 0.4.1`.
